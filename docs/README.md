## Documentación académica consolidada

Los documentos Word y PowerPoint originales se conservaron fuera de este repositorio durante la preparación pública porque pueden contener datos personales y versiones históricas duplicadas. Sus conclusiones verificables se preservan en los documentos Markdown de auditoría, trazabilidad y requerimientos enlazados arriba. No se eliminaron ni sobrescribieron los archivos originales.

## Convención de evidencia

- **AS-IS:** comprobado en código o configuración del proyecto.
- **Parcial:** implementado, pero con validación física o de aceptación pendiente.
- **TO-BE:** propuesto; no forma parte de la implementación actual.
- **No determinado:** la evidencia disponible no permite afirmarlo.
